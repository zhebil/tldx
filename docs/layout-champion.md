# Layout champion report

Phase B baseline. Generated by `tools/layout-report.mts` over every file in
`tests/corpus/`. The output is deterministic - regenerating on an unchanged
tree produces a byte-identical file.

```bash
for f in tests/corpus/*.tldsl.jsx; do npx tsx tools/layout-report.mts "$f"; done
```

Replace this file whenever a hypothesis is KEPT; it is the comparison baseline
for the next wake's candidate, per the Phase B protocol in `docs/ralph-plan.md`.
